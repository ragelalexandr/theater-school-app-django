Техническое задание:

Для пользователя (студента/посетителя) реализовать функционал:
1. Регистрации и авторизации с возможностью восстановления пароля через электронную почту.
2.Настройки профиля: редактирование личных данных (имя, контактная информация), загрузка 
фотографии, изменение пароля, удаление учетной записи.
3. Просмотр расписания: отображение списка курсов с датами, временем и доступностью. 
4. Запись на театральные курсы: выбор курса, выбор преподавателя, выбор типа прохождения (
персональное или парное), выбор периода прохождения (даты начала и окончания), подтверждение записи.
5. Создание и редактирование портфолио: добавление фотографий, видеозаписей, текстовых описаний
достижений, возможность удаления или изменения элементов портфолио.
6. Просмотр истории: отображение списка записей на курсы с указанием статуса (ожидание, подтверждено,
завершено). 
7. Оставление отзывов.



Для преподавателя реализовать функционал:
1. Авторизации с использованием учетных данных.
2. Просмотр списка курсов и студентов: отображение информации о своих курсах и записанных студентах
(имя, тип прохождения, даты). 
3. Управление записями студентов: Просмотр заявок на курсы, подтверждение или отклонение записей.


Для администратора реализовать функционал:
1. Управления базами данных
2. добавление, редактирование и удаление данных о:
2.1. театральных представлениях (название, дата, описание)
2.2. курсах (название, преподаватель, расписание)
2.3. преподавателях (имя, специализация)
2.4. студентах (профильные данные)
3. модерация отзывов.



Исходя из ТЗ, многое мы реализовали, но есть несколько областей, которые остались без явной реализации или реализованы не полностью:
Выбор преподавателя для курса. Техническое задание предусматривает, что при записи на курс студент должен выбирать преподавателя. В нашей реализации запись на курс происходит через выбор уже существующего курса, в котором преподаватель определяется заранее (например, через поле instructor в модели Course). Мы не реализовали интерфейс, позволяющий студенту выбирать преподавателя из списка вариантов.
Детализация расписания курсов. Задание требует отображения расписания – списка курсов с датами, временем и доступностью. Хоть отображение курсов реализовано, отсутствуют подробные данные (например, время проведения, конкретный формат расписания или календарное представление), что можно доработать для наглядности.
Функциональность для театральных представлений. Для администратора требуется управление базами данных, включающее работу с данными о театральных представлениях (название, дата, описание). Мы не создали отдельную модель и интерфейс для представлений (performance), а сосредоточились только на курсах, отзывов, портфолио и записях.
Наличие отдельной модели для преподавателей с характеристиками. ТЗ упоминает данные о преподавателях (имя, специализация) для управления ими. В нашей реализации преподаватель хранится, например, как строка в модели курса или через стандартную модель пользователя. Мне не удалось увидеть отдельную модель, агрегирующую информацию по преподавателям (например, с полем специализации, биографией и т.п.).
Расширенные возможности администрирования. Техническое задание для администратора предполагает не только модерацию отзывов, но и возможность добавлять, редактировать и удалять записи о курсах, представлениях, преподавателях и студентах. Основные возможности администрирования в нашей реализации обеспечиваются через стандартную Django admin-панель, но отдельный UI для этих задач (на стороне фронтенда) не был создан.
В итоге, основная функциональность для пользователя, преподавателя и администратора реализована, но для полного соответствия ТЗ можно доработать следующие моменты:
Добавить в процесс записи выбор конкретного преподавателя.
Создать отдельные модели и интерфейсы для театральных представлений и для преподавателей с подробными данными.
Улучшить представление расписания (например, календарь или детальное расписание с временем проведения).
Расширить административный раздел, если требуется, не полагаясь только на стандартную административную панель Django.
